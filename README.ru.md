# SillyTavern QoL Pack

[English](README.md) · Русский

Пакет небольших улучшений для SillyTavern: виджет лимита сохранённого ключа и отображение модели рядом с ответами OpenRouter.

[**Скачать последний релиз**](https://github.com/AmadeusTwi/sillytavern-qol-pack-releases/releases/latest)

## Установка

1. Скачайте **SillyTavern-QoL-Pack-&lt;версия&gt;.zip** и распакуйте в любую папку, например «Загрузки».
2. Откройте `Install-Windows.cmd`, `Install-macOS.command` или запустите `Install-Linux.sh` в терминале.
3. Выберите папку установленной SillyTavern и подтвердите установку.
4. Перезапустите SillyTavern и обновите страницу в браузере.

Запускайте установщик на компьютере, где установлена сама SillyTavern. Нужны Node.js 20.12+ и SillyTavern 1.19+.

Выберите OpenRouter и сохранённый активный ключ. Рядом с **API Connections** появится ключик, который открывает компактный виджет остатка лимита. Язык виджета зависит от языка SillyTavern: русский при выбранном русском, английский — во всех остальных случаях.

## Модель рядом с ответом

У ответов OpenRouter рядом с иконкой маршрутизатора появляется штатный логотип семейства модели, если он есть в SillyTavern: Claude, OpenAI, DeepSeek, Z.AI, Google и другие.

Тапните или нажмите на группу иконок — справа раскроется читаемое название из списка моделей в **API Connections**. Повторное нажатие, клик снаружи или Escape закрывают подпись. Enter и пробел тоже работают. Длинные названия на узком экране переносятся, а не обрезаются.

Каждый ответ и выбранный свайп используют собственные записанные метаданные. Переключение текущего провайдера или модели не меняет подписи старых ответов. Если модели нет в загруженном каталоге, используется читаемый вариант сохранённого идентификатора. Если модель не записана, подпись сообщает об этом.

Модуль учитывает настройку **User Settings → Model Icons** и режим документа. Данные чата не изменяются, дополнительных запросов к OpenRouter нет. Мобильная вёрстка и касания проверены в браузерной эмуляции; ощущения от тапа ещё нужно проверить на физическом телефоне.

## Обновления

Виджет автоматически проверяет GitHub Releases, сохраняя результат на шесть часов. Если доступно обновление, на ключике появится индикатор.

Откройте **«О пакете и обновлениях» → «Установить v…»**, затем перезапустите SillyTavern и обновите страницу. UI и серверный плагин обновятся вместе. В этом же разделе можно вернуть предыдущую установку. Установка обновлений и откат доступны администратору SillyTavern.

Версии 0.4.1 и 0.4.2 обновляются до 0.4.3 прямо из виджета. Совместимый файл для 0.4.0 оставлен только в переходном релизе 0.4.2. Если вы остались на 0.4.0 и пропустили переход, один раз запустите последний установщик.

## Репозиторий

Здесь хранятся готовые релизы и пользовательская документация. Репозиторий разработки пока закрыт. Архивы релизов содержат исполняемый JavaScript, необходимые зависимости, лицензию и уведомления о сторонних компонентах.

Установка проверена на macOS с SillyTavern 1.19. Запускатели для Windows и Linux на этих системах пока не проверены.
